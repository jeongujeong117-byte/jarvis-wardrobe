# 디자인 개선 검증 기록

검증일: 2026-09-09. Expo 웹 미리보기 기준이며 실기기 검증이나 실제 계정 저장 검증을 대신하지 않는다.

## 적용 범위

- 시작 화면, 오늘의 코디, 내 옷장, 마이, 로그인·회원가입, 직접 등록 화면.
- 따뜻한 흰색·스톤 배경, 절제된 라벤더·블러시 강조, 그래파이트 주 버튼.
- 공통 색상 토큰, 선형 아이콘, AI 생성 샘플 의류 이미지.
- 검색·분류·상세 표시, 코디 변경·선택, 등록 오류·인증 오류의 인라인 안내.
- 샘플 가져오기는 기존 옷을 삭제하지 않고 중복 ID를 제외해 추가.

## 확인한 항목

- TypeScript 검사: `npx tsc --noEmit`.
- ESLint: `npm run lint`.
- 변경 공백 검사: `git diff --check`.
- 데스크톱 1200×900, 모바일 390×844의 시작·오늘·옷장·등록·계정 화면 확인.
- 샘플 옷장 진입, 예시 코디 변경, 코디 선택 후 버튼 비활성화.
- 옷 이름 검색, 카테고리 필터, 검색 결과 없음 안내.
- 비로그인 직접 등록 후 옷 개수 증가 및 ‘사진 미등록’ 표시 확인. 테스트 자료는 새로고침으로 제거.
- 로그인 화면 열기·닫기와 빈 입력 오류 확인.
- 샘플 주문 가져오기 상품 선택 및 캡처 샘플 흐름 확인.

## 실제 서비스 연결과의 경계

- Gmail, 캡처 인식, 날씨와 추천은 데모다. 실제 AI 모델을 호출하지 않는다.
- 상황 선택은 제목과 설명을 바꾼다. 상황에 적합한 옷을 분석하는 기능은 후속 작업이다.
- 샘플과 로그인 전 직접 등록한 옷, 코디 선택은 메모리에서만 유지된다.
- Supabase 로그인·직접 등록 저장 코드는 유지했지만 이번 디자인 검증에서 실제 회원가입이나 사용자 데이터 쓰기는 수행하지 않았다.
- 실기기 키보드, 글자 확대, 스크린리더, 실제 로그인·가입 확인메일·저장·오류 재시도는 후속 검증 대상이다.

## 실행 환경 참고

현재 로컬 의존성 폴더의 파일 감시 오류 때문에 `CI=1`로 서버를 실행했다. 이 임시 모드는 자동 새로고침을 끄며 소스 수정 후 서버를 재시작해야 한다. 의존성 복구나 패키지 업그레이드는 이번 PR에 포함하지 않는다.

## 이미지 출처와 생성 브리프

최종 자산: `assets/images/wardrobe-atlas.png` (1536×1024). 이 앱의 샘플 시연을 위해 AI로 생성했으며 다른 서비스의 상품 사진을 복제하지 않았다. 실제 사용자 의류 사진이 아니다.

생성 브리프: 정확한 3열×2행 그리드, 각 셀 512×512, 따뜻한 흰색 `#F6F5F2` 바탕. 왼쪽 위부터 오프화이트 옥스포드 셔츠, 네이비 티셔츠, 블루 데님, 베이지 팬츠, 슬레이트 그레이 재킷, 화이트 가죽 스니커즈. 각 의류를 중앙에 배치한 사실적인 에디토리얼 스튜디오 플랫레이, 부드러운 그림자, 텍스트·로고 없음.

이미지는 `gmail-1`~`gmail-6` 샘플 ID에만 연결한다. 직접 등록한 옷은 같은 카테고리여도 생성 이미지를 임의로 입히지 않고 사진 미등록 상태와 색상 스와치를 보여준다.
