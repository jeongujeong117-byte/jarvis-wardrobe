# Phase 4 — 컴포넌트 분해 및 토큰 적용

> 전제: Phase 3 토큰 완료. 기능 흐름은 건드리지 않는다.

## 지시

1357줄 단일 파일을 해체하고 토큰을 적용한다. **티켓 단위로 쪼개서 순차 진행**한다.

### 먼저 티켓을 만든다

`docs/ui/04-tickets.md` 에 작업을 분해한다. 각 티켓은:
- 혼자서 완결되고
- 끝난 시점에 앱이 정상 동작하며
- 전/후 스크린샷으로 검증 가능해야 한다

권장 순서 (의존성 순):
1. 기반 컴포넌트 추출 (Text, Surface, Divider)
2. 상호작용 컴포넌트 추출 (Button, Chip, IconButton, Tile)
3. 레이아웃 컴포넌트 추출 (Screen, Header, Section)
4. 아이콘 체계 교체 (텍스트 글리프 → 선택된 아이콘 세트)
5. 화면별 파일 분리 — 한 번에 한 화면씩
6. 다크모드 연결 (`_layout.tsx`의 StatusBar 고정 해제 포함)
7. 모션 추가 — 마지막. 구조가 끝난 뒤에만

### 각 티켓 수행 규칙

- 시작 전: 바꿀 파일과 예상 영향 범위를 보고한다
- 수행 중: 하드코딩 값을 새로 만들지 않는다. 토큰에 없으면 토큰을 먼저 추가한다
- 끝난 뒤: `npm run lint` + TS 체크 + 해당 화면 스크린샷
- 커밋 메시지에 "무엇을 / 왜 / 어떤 원칙"을 적는다

## 금지

- 여러 티켓을 한 번에 진행하지 않는다
- 기능 로직(상태 전환, 데이터 호출, Supabase)을 수정하지 않는다
- 동작이 깨진 채로 다음 티켓에 넘어가지 않는다
