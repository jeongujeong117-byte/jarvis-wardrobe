# 06 — 모더니즘 × 손의 선: 요소 분석과 시안 설계

> 사용자 정정 (2026-11-03 02:49): 참조 앱의 디자인을 **차용하지 말 것**.
> 원하는 것은 ① 간단한 색의 조합과 적은 선으로 만든 **모더니즘적 감각**, ② **유려한 필체**와 **부드러운 만년필 드로잉**.
> → v2(몬드리안 격자 + Clutter 차용)는 폐기하고 새 방향을 세운다. 기능·데이터·토큰 구조는 유지.

## 1. "모더니즘의 간결한 감성"은 무엇으로 이루어지나

| # | 요소 | 무엇을 하는가 | 화면 규칙으로 번역 |
|---|---|---|---|
| 1 | **환원** (Mies, "less is more") | 각 요소가 일을 해야만 남는다 | 장식용 박스·배지·구분선 없음. 정보가 없으면 그리지 않는다 |
| 2 | **여백이 재료** | 빈 곳이 시선을 조직한다 | 섹션 사이 48pt 이상. 화면의 40% 이상이 비어 있어도 된다 |
| 3 | **비대칭 그리드** (스위스 양식) | 정렬이 질서를 만든다 | 왼쪽 정렬·오른쪽 흘림. 한 개의 세로 기준선에 모두 맞춘다 |
| 4 | **제한된 색** | 색이 적을수록 각 색이 의미를 갖는다 | 종이 1 + 잉크 1 + (옷의 색). UI 자체의 색은 사실상 없음 |
| 5 | **면은 평평하게** | 깊이를 흉내내지 않는다 | 그림자·그라디언트·유리 효과 없음. 색은 납작한 면 |
| 6 | **선의 경제** | 선 하나하나가 구조를 맡는다 | 화면당 구조선 2개 이하. 테두리로 덩어리를 만들지 않는다 |
| 7 | **글자가 곧 구조** | 크기·굵기 대비가 위계를 만든다 | 상자 대신 글자 크기 차이로 계층. 굵기는 2단계 |
| 8 | **기능의 정직함** | 보이는 대로 작동한다 | 누를 수 있는 것은 누를 수 있어 보인다. 장식 아이콘 없음 |

## 2. 손의 선 — 왜 모더니즘과 붙는가

모더니즘이 차갑게 식는 지점에서 **손**이 온기를 넣는다. 마티스·피카소의 한 줄 드로잉, 장 콕토의 펜화가
기하학적 화면 옆에서 빛났던 이유다. 한국어 화면에선 **여백**(餘白) 개념이 모더니즘의 빈 공간과 정확히 겹친다.

| 손의 요소 | 만년필이 만드는 특징 | 규칙 |
|---|---|---|
| **획의 굵기 변화** | 펜촉 각도에 따라 내려긋는 획은 굵고, 올리는 획은 가늘다 | 균일한 SVG 선 금지 → `tools/design/pen.py`가 펜촉을 시뮬레이션해 굵기가 변하는 외곽선을 만든다 |
| **획의 시작과 끝** | 펜이 닿을 때·뗄 때 잉크가 가늘어진다 | 획 양 끝 테이퍼 |
| **잉크 색** | 순수한 검정이 아니라 블루블랙 | 잉크 = `#1F2A44` 계열 (시안별로 조정) |
| **유려한 필체** | 이어지는 기울어진 글씨 | 필기체는 **이름·서명·한마디**에만. 기능 정보(버튼·라벨·숫자)에는 절대 쓰지 않는다 — 가독성 |
| **표시하는 손** | 펜으로 동그라미 치고 밑줄 긋기 | 선택 상태를 상자 대신 **펜 동그라미/밑줄**로 |

**한 문장 원칙: 구조는 기계가, 의미는 손이.**
그리드·산세리프·납작한 색면이 모든 기능을 맡고, 손(필기체·펜 드로잉)은 사람이 기억할 순간에만 나온다.

## 3. 쓰지 않을 것 (스킬 기반 금지 목록)

출처: `frontend-design`, impeccable `craft-floor`, Expo `native-slop`.

- 제목 위의 작은 라벨(eyebrow) — impeccable 금지 항목. v2의 "8월 27일 목요일", "보관 중인 옷"이 해당
- 큰 숫자 + 작은 라벨 카드(hero-metric 템플릿) — v2의 "6벌", "1회" 카드가 해당
- 헤드라인에서 한 단어만 색 바꾸기 — v2의 "이렇게 입어요" 빨강이 해당
- `A · B · C` 가운뎃점 메타 문자열 — v2 곳곳
- 1px 넘는 색 세로줄 강조 — v2의 개인정보 안내 박스
- 크림 배경 + 세리프 + 테라코타 — AI 디자인의 첫 번째 상투형. 종이색은 **차가운 흰색**으로
- 같은 모양 카드의 반복, 카드 안의 카드

## 4. 세 시안

모두 1~2절을 공유하고, **손과 기하의 비중**이 다르다.

### A. 여백과 획
- 종이 `#FBFBF9` · 잉크 블루블랙 `#1F2A44` · 옷 색만이 유일한 색. 낙관(도장) 주홍 한 점은 워드마크에만
- 옷 = **평평한 색면 위에 살짝 어긋나게 겹친 만년필 윤곽** (판화의 어긋난 판, 마티스의 색종이)
- 필기체: Mrs Saint Delafield (가장 만년필다움) — 워드마크와 요일
- 선택 = 단어를 둘러싼 **펜 동그라미**
- 위험: 여백이 많아 정보 밀도가 낮다

### B. 점·선·면
- 칸딘스키 『점·선·면』: 옷을 **원·사각·반원** 같은 기본 도형의 색면으로, **펜 선 한 줄**이 그것들을 잇는다
- 흰 종이 · 먹색 잉크. 필기체: Ms Madi (현대적)
- 위험: 옷이 도형으로 추상화되어 "무슨 옷인지" 인식이 느려진다

### C. 편지
- 앱이 **손글씨 메모**로 말한다: "맑고 24도. 옥스포드 셔츠에 원턱 팬츠…" (나눔펜) — 이것이 주인공
- 펜 스케치는 여백에 작게, 색은 작은 원 견본. 기준선 몇 줄
- 위험: 한글 손글씨의 가독성, 귀여운 인상으로 흐를 수 있음

### 판정

- **A 채택.** "평평한 색면 + 어긋나게 겹친 만년필 윤곽"이 이 앱만의 서명이 된다. 옷의 색(모더니즘의 면)과 옷의 형태(손의 선)가 한 요소에서 만난다. 선택을 펜 동그라미로 표시하는 방식이 상태를 가장 분명히 보여준다.
- **결함 (렌더에서 발견):** 남색 티셔츠 위 잉크 선이 **1.41:1**로 거의 보이지 않는다. → 색면과 겹치는 부분만 선을 종이색으로 바꾼다(판화의 반전). `onColor()`로 색마다 자동 결정.
- **B 기각:** 가장 모더니즘적이지만 옷이 원·사각형으로 추상화되어 "무슨 옷인지"가 사라진다(인식 1점). 펜 선 한 줄은 의미 없이 장식으로 읽힌다.
- **C에서 가져올 것:** 옷장 목록의 **스캔 효율**. 다만 한글 손글씨(나눔펜)는 귀여운 인상으로 흘러 "유려한 필체"와 거리가 있어 채택하지 않는다.

### 최종안 = A + 보정

1. 선 반전 클리핑 (위 결함)
2. 필기체(Mrs Saint Delafield)는 **워드마크**와 오늘 코디 아래의 **요일 서명** 두 곳에만 — 화가가 그림에 서명하듯
3. 테마 4종 선택 기능 제거 → 시스템 라이트/다크 자동 2종 (색 조합의 간결함, 참조 앱 기능 차용 제거)
4. v2의 금지 목록 위반 전부 제거: 제목 위 라벨, 큰 숫자 카드, 한 단어 강조, 가운뎃점, 굵은 색 세로줄, 카드 배경 목록
5. 굵기 2단계(400/500), 구조선은 탭바 위 머리카락선과 목록 구분선뿐
