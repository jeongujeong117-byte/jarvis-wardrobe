## 현재 연구 판단

- 동결된 FashionCLIP 이미지 특징과 규제 로지스틱 회귀를 우선 복구합니다.
- 기존 개발 예측에서 전체 이미지 특징 모델의 이미지 분리 AUC는 약 0.680이었습니다. 저장 예측으로 재계산한 값이며, 정확도 68% 또는 새로 학습한 결과를 뜻하지 않습니다.
- 전신 착샷 선호 예측과 개별 보유 옷의 조합 추천은 입력·평가 목표가 다릅니다. 앱에서는 제약·명시적 선호·실제 피드백을 연결합니다.
- 다음 확보 대상은 과거 학습 입력 묶음 `fashion_colab_inputs.zip`, AI Hub 응답·대응 이미지, 특징 추출기와 모델 파일입니다.

## 자료 범위

이 폴더에는 작성한 연구 문서를 보관합니다. 문서에 언급된 원본 CSV·사진·학습 입력 ZIP·모델 가중치는 저장소에 포함되어 있지 않습니다. 문서의 로컬 경로는 작성 당시 자료 위치이며 다른 PC에서는 경로를 바꿔야 합니다. 과거 프로토타입 검토 내용은 해당 로컬 작업본 기준이므로 현재 기본 브랜치의 기능과 다를 수 있습니다.

기존 실행기록과 개발 성능은 최종 독립 검증 또는 실제 착용 만족의 검증 결과와 구분합니다. 데이터셋·스킬 원문과 방법론 출처는 각 문서의 참고자료에 기재했습니다.
